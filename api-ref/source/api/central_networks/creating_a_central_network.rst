Creating a Central Network
==========================

Function
--------

This API is used to create a central network.

URI
---

POST /v3/{domain_id}/gcn/central-networks

   ========= ========= ====== ===========
   Parameter Mandatory Type   Description
   ========= ========= ====== ===========
   domain_id Yes       String Account ID.

Example Requests
----------------

Creating a central network

.. code-block:: text

   POST /v3/{domain_id}/gcn/central-networks

   {
     "central_network" : {
       "name" : "name"
     }
   }
