Updating a Central Network
==========================

Function
--------

This API is used to update a central network.

URI
---

PUT /v3/{domain_id}/gcn/central-networks/{central_network_id}

.. table:: **Table 1** Path Parameters

   ================== ========= ====== ===================
   Parameter          Mandatory Type   Description
   ================== ========= ====== ===================
   domain_id          Yes       String Account ID.
   central_network_id Yes       String Central network ID.
   ================== ========= ====== ===================

------------------

Example Requests
----------------

Updating a central network

.. code-block:: text

   PUT /v3/{domain_id}/gcn/central-networks/{central_network_id}

   {
     "central_network" : {
       "description" : "new description"
     }
   }
